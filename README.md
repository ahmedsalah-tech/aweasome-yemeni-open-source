## About This Directory

Yemeni Open Source is a community-maintained directory that makes open-source work by Yemeni technologists easier to discover, use, and support.

Our goals are to:

- Showcase high-quality open-source projects created or substantially maintained by Yemenis.
- Help developers discover useful libraries, tools, educational resources, and opportunities to contribute.
- Give project maintainers greater visibility while preserving their ownership and independence.
- Encourage collaboration, knowledge sharing, and sustainable open-source development.

> [!IMPORTANT]
> Projects remain in their original repositories and under the ownership and governance of their respective maintainers. Listing a project here does not transfer ownership to Yemen Tech Collective and does not constitute a security, quality, or maintenance guarantee.

## Add a Project

We welcome projects from Yemeni developers, designers, researchers, maintainers, and technical communities.

A submitted project should:

- Be publicly accessible and genuinely open source.
- Include an explicit open-source license.
- Have a clear `README` explaining its purpose and usage.
- Be created or substantially maintained by at least one Yemeni contributor.
- Provide meaningful value as software, tooling, documentation, design resources, data, research, or technical education.
- Not contain malicious, deceptive, discriminatory, illegal, or politically partisan content.

To submit a project:

1. Fork this repository.
2. Add the project to the end of the table using the existing format.
3. Keep the description factual, concise, and free of promotional claims.
4. Open a pull request titled `Add: owner/project-name`.
5. Include evidence of Yemeni creation or substantial maintenance when it is not apparent from the repository.

Suggested pull request details:

```text
Project name:
Repository URL:
Maintainer(s):
Category:
Short description:
Open-source license:
Relationship to Yemen:
```

## Review and Curation

Yemen Tech Collective may edit descriptions for clarity and consistency, request missing information, reorder or recategorize entries, or remove projects that no longer meet the directory criteria. Acceptance is based on transparent editorial and community-safety considerations, not on personal affiliation.

Projects may later be highlighted as:

- **Listed:** Independently owned and included in this directory.
- **Incubated:** Independently owned or organization-hosted, with structured community support.
- **Official YTC:** Governed and maintained as an official Yemen Tech Collective project.

Unless explicitly marked otherwise, every project in this directory is **Listed**.

## Contributing

Contributions that improve project descriptions, fix broken links, add categories, translate content, or improve the directory structure are welcome through pull requests.

Please treat maintainers and contributors with professionalism and respect. Contributions should follow the [Yemen Tech Collective](https://yementc.org) community values of professionalism, neutrality, inclusion, respect, and knowledge sharing.
